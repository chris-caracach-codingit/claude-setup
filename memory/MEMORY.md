# Team conventions

How Christian works, distilled into a few convention docs. These are drop-in Claude Code memory files — copy the ones you want into your own `~/.claude/projects/<project>/memory/` (or point Claude at this folder). Personal and live-ticket memories are intentionally excluded.

- [git.md](git.md) — Git conventions — commit messages, history discipline, branch naming
- [pull-requests.md](pull-requests.md) — Pull request conventions — title, body format, voice, and GitHub etiquette
- [code-style.md](code-style.md) — Code style — React/TSX idioms, CSS units, comments, and fixing at the root
- [execution-guardrails.md](execution-guardrails.md) — Things Claude must not run or change on its own — the user controls these
- [linear-tickets.md](linear-tickets.md) — Linear ticket conventions — cycles, descriptions, and reading specs
- [wiki-and-notes.md](wiki-and-notes.md) — How to write to the wiki / Obsidian vault — granularity and cadence
- [working-style.md](working-style.md) — How Claude should communicate and handle information
